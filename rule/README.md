# Regras do projeto — Calculadora de Água

Este guia reúne as regras que **todos os integrantes** devem seguir ao criar conteúdo, código, layout e entregas do site.

O README principal do repositório permanece na raiz. Este índice só organiza as regras por tema.

## Como usar

1. Leia o arquivo do tema **antes** de alterar a tela correspondente.
2. Avise o grupo o que pretende mudar (veja [05-colaboracao.md](05-colaboracao.md)).
3. Só avance para a próxima tela depois da aprovação combinada pelo grupo.

## Tecnologias

O site é feito em **HTML5** e **CSS3**. **JavaScript** é permitido nas telas que precisam de interatividade: calculadora (`agua.js`), resultado (`resultado.js`) e quiz (`quiz.js`).
